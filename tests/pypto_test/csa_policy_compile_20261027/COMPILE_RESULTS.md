# TND CSA 全 policy 编译实测

算子基线 `6acb0ce9d`；公共工具链 `csa-shared-20261024-group-dims`；CANN 9.2。

正常入口全部编译成功：SPMD 94 项，MPMD 55 项。关闭 PyPTO 持久缓存，每项独立首次编译。

**这轮是 8→32 路并发预编译；逐项耗时求和不是串行实测，也不是 CPU 时间。**
单次耗时包含并发资源竞争；真正逐项串行的总时间尚未测量。

缓存命中只测相同 artifact 的解析和 load，不是 forward 或跨进程命中的耗时。

SPMD 每项生成 AIC/AIV 两个设备 kernel，另有 AICPU 编排；MPMD 为 43/44 个设备 kernel 加编排。
MPMD 任务较小、可并行编译，SPMD 单份设备编译更重；该拆分仅用于解释观测，尚未单独剖析 C++ 编译器热点。
