# CSA 接入调用链示意图

本文对照现有 Python PTO 模型接入与拟增加的 ACLNN 后端。
右侧 ACLNN 单算子工程已经存在；将它接入同事的模型分支仍是方案，不能据此认为整模型接入已完成。

```mermaid
flowchart TD
    A["模型层 csa_layer_forward()"] --> B["torch.ops.vllm.dsv4_csa_forward()"]
    B --> C{"当前输入是否支持 CSA？"}
    C -->|否| N["原 Native attention 路径"]
    C -->|是| D["CSAServiceRuntime"]
    D --> E["bind_native_inputs()<br/>准备权重、输入、KV cache、页表、位置等"]
    E --> F["select_policy()<br/>选择策略；按描述符和策略缓存绑定"]
    F --> G["_prepare_binding()<br/>这里选择后端"]

    G -->|现有路径| P1["PreparedDynamicCSA<br/>保存 Tensor 绑定和 policy"]
    G -.->|拟增加的 ACLNN 路径| Q1["PreparedAclnnCSA<br/>复用参数绑定；policy 匹配 tiling key"]

    P1 --> P2["prepared()<br/>PreparedDynamicCSA.__call__()"]
    P2 --> P3["decode_csa_spmd()<br/>PyPTO 编译或复用编译缓存"]
    P3 --> P4["Simpler 执行生成的调度代码<br/>管理内部临时 Tensor / workspace"]
    P4 --> P5["提交生成的 AIC / AIV 核"]

    Q1 --> Q2["prepared()<br/>PreparedAclnnCSA.__call__()"]
    Q2 --> Q3["torch.ops.csa_pto.run(buffers, variant)"]
    Q3 --> Q4["Torch C++ binding<br/>EXEC_NPU_CMD"]
    Q4 --> Q5["ACLNN GetWorkspaceSize / Host tiling<br/>按 key 选择 LayoutN，计算大小和偏移"]
    Q5 --> Q6["torch_npu 调用流程<br/>申请 workspace 并调用 ACLNN 执行"]
    Q6 --> Q7["Kernel wrapper<br/>按来源和偏移恢复指针、转换类型"]
    Q7 --> Q8["按 tiling key 调用<br/>已编译的 cube_schedule / vector_schedule"]

    P5 --> R["NPU 执行 CSA<br/>写回 output 和 KV / state cache"]
    Q8 --> R
    R --> S["服务层通知 cache 已更新<br/>继续模型后续计算"]
```

## 怎么理解这个替换

- **分叉前复用**：模型路由、Native 参数准备、policy、绑定缓存和图合同。
- **Python PTO 路径**：PyPTO/Simpler 管理编译、提交和内部临时内存。
- **ACLNN 路径**：Host 计算布局，调用框架申请 workspace，内核包装层按偏移传参。
- `PreparedAclnnCSA` 内部仍调用 `PreparedDynamicCSA` 准备参数和 policy，但不调用它的 `__call__()`；替换的是执行路径，不是重写所有参数准备逻辑。
- 图展示准备及普通执行流程。绑定可缓存、同描述符输入可 rebind；图捕获后的 replay 不会每次重新走所有 Python 步骤。
- 当前 ACLNN 适配使用带 Top-K 输出的诊断合同，会在准备阶段补齐两张 Top-K 输出；不能把它与 Python 正常入口的 55 Tensor 合同直接混同。

## 关键代码位置

同事模型分支（只读参考，不在本次文档工作中修改）：

`/data00/wangkai/pto_env/xllm-vllm-ascend`

- `vllm_ascend/models/pypto_deepseek_v4.py`：模型层接管入口。

- [runtime.py](runtime.py)：`PreparedAclnnCSA`，policy 精确匹配 tiling key，调用 Torch 算子。
- [torch/binding.cpp](torch/binding.cpp)：`EXEC_NPU_CMD` 接入。
- [op_host/csa_spmd_tnd_pto.cpp](op_host/csa_spmd_tnd_pto.cpp)：Host tiling 和 workspace 大小申报。
